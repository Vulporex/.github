# Security policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities or sensitive data through public GitHub issues or discussions.

Contact **info@sigmafirefox.online** with the subject **Vulporex security report** until a dedicated Vulporex security mailbox is established. Include the affected repository, reproduction steps, impact, and a safe contact method. Do not send credentials or real personal data.

Where a repository has GitHub private vulnerability reporting enabled, prefer that channel.

## Scope and support

Security fixes are prioritized for actively maintained products. Individual repositories may document supported versions and additional security contacts.

## Disclosure

Please allow time for investigation and remediation before public disclosure. We will coordinate a responsible disclosure timeline with reporters where possible.
